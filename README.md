# Проект: Анализ выживаемости пассажиров Титаника

## О проекте
Индивидуальный цифровой проект. Цель — построить модель бинарной классификации для предсказания выживания пассажиров.

**Датасет:** Titanic Dataset (Large-Scale Passenger Survival) с Kaggle.
**Размер:** 100 000 строк, 31 столбец.

## Структура репозитория
*   `notebooks/stage2_data_audit.ipynb` — Jupyter ноутбук с кодом первичного аудита (скачан из Google Colab).
*   `reports/` — результаты работы (графики, HTML-профиль таблицы).
*   `requirements.txt` — библиотеки, необходимые для запуска.

# Этап 2. Первичный аудит данных

В ходе аудита в ноутбуке были получены следующие результаты:

1.  **Пропуски:** Обнаружены в 4 признаках (`occupation`, `cabin_deck`, `medical_condition`, `emergency_response_time`). Заполнены медианой и модой. Текущее количество пропусков: 0.
2.  **Дубликаты и константы:** Не обнаружены.
3.  **Баланс классов:** Наблюдается дисбаланс. Погибли — 71.48%, выжили — 28.52%. Это требует использования метрик ROC-AUC и F1-score на этапе моделирования.
4.  **Аномалии (Выбросы):** 
    *   `ticket_price`: 10.55% (являются реальными данными, удалять не будем, применим RobustScaler).
    *   `age`: 2.35%.
