# Проект: Анализ выживаемости пассажиров Титаника

## О проекте
Индивидуальный цифровой проект. Цель — построить модель бинарной классификации для предсказания выживания пассажиров.

**Датасет:** Titanic Dataset (Large-Scale Passenger Survival) с Kaggle.
**Размер:** 100 000 строк, 31 столбец.

## Структура репозитория
*   `notebooks/stage2_data_audit.ipynb` — Jupyter ноутбук с кодом первичного аудита (скачан из Google Colab).
*   `reports/` — результаты работы (графики, HTML-профиль таблицы).
*   `requirements.txt` — библиотеки, необходимые для запуска.

# Этап 3. Исследовательский анализ и признаки

Для выполнения этапа было создано два блокнота в папке `notebooks`:
1. `stage3_part1_eda.ipynb` — Анализ данных (выборка 25%, графики, проверка гипотез на оставшихся 75%).
2. `stage3_part2_preprocessing.ipynb` — Предобработка (масштабирование, разделение выборки, кодирование).

## Часть 1. Анализ данных и гипотезы

Для анализа была взята случайная выборка (25% датасета). Оставшиеся 75% использовались для проверки гипотез, чтобы избежать переобучения на этапе исследования. Были выдвинуты и проверены 3 гипотезы:

1.  **Гипотеза 1: Женщины выживали чаще мужчин.** 
    *   *Ход мыслей:* Исторически при эвакуации действовало правило «Женщины и дети первыми», поэтому у женщин должен быть выше шанс на спасение.
    *   *Результат проверки:* Подтвердилась. Выживаемость женщин — **37.9%**, мужчин — **20.1%** (Non-Binary — 20.4%). Шансы женщин почти в 2 раза выше.
2.  **Гипотеза 2: Пассажиры 1-го класса выживали чаще, чем 3-го.**
    *   *Ход мыслей:* Пассажиры 1-го класса имели больше денег и привилегий, их каюты располагались ближе к верхним палубам и шлюпкам.
    *   *Результат проверки:* Подтвердилась. Выживаемость 1-го класса — **49.1%**, 2-го — **33.8%**, 3-го — **21.3%**. Прослеживается четкая связь между социальным статусом и выживанием.
3.  **Гипотеза 3: Доступ к шлюпкам напрямую влияет на выживание.**
    *   *Ход мыслей:* Признак `lifeboat_access` показывает близость пассажира к спасательным средствам. Если доступ > 0.5, шансы спастись должны быть выше.
    *   *Результат проверки:* Подтвердилась. При доступе > 0.5 выживаемость составила **39.75%**, при доступе <= 0.5 — **21.80%**.

**Вывод по Части 1:** Все три гипотезы успешно подтверждены на отложенной части данных. Признаки `gender`, `class` и `lifeboat_access` являются сильными предикторами для будущей модели.

## Часть 2. Предобработка данных

1.  **Разделение выборки:** Данные разделены на Train (80%, 80 000 строк) и Test (20%, 20 000 строк) со стратификацией по целевой переменной, чтобы сохранить баланс классов в обеих выборках.
2.  **Масштабирование:** Для тестирования был выбран признак `ticket_price`. Были применены `StandardScaler`, `MinMaxScaler` и `RobustScaler`. Поскольку в цене билета есть выбросы (около 10%), наиболее подходящим признан **RobustScaler**, так как он использует медиану и межквартильный размах и не чувствителен к аномалиям.
3.  **Полная предобработка:** 
    *   Все числовые признаки отмасштабированы с помощью `RobustScaler` (обучен строго на Train, применен к Train и Test).
    *   Все категориальные признаки (текстовые) переведены в числовой формат с помощью `One-Hot Encoding`.
    *   В результате количество признаков увеличилось с 28 до 61 (за счет разбивки категорий на отдельные столбцы-флаги).

**Вывод по Части 2:** Данные полностью подготовлены к обучению моделей машинного обучения. Размер обработанного Train: 80 000 строк, 61 признак. Тест: 20 000 строк, 61 признак.
